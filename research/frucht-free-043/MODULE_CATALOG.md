# Указатель 46 модулей Frucht Free 0.4.3

Классификация по проверенным объявлениям функций, импортам и контекстам вызова в исходном архиве. Это карта **пакета**, не утверждение, что все функции доступны пользователю в бесплатной Kiwi-редакции. Роли сжаты, исходный GPL-код не перепечатывается.

| Модуль | Основная роль / что искать |
|---|---|
| `__init__.py` | Register/unregister аддона, доступ к Python API и панелям |
| `edition.py` | Фильтр доступных фруктов Free; активен Kiwi |
| `fruechte.py` | Реестр типов плода, имена объектов, рецепты режимов и параметров, категории перестройки |
| `neu.py` | Создание плода из пакета `.blend`, проверки наличия, восстановление сессии |
| `api.py` | Программное управление: создать, изменить форму, добавить срез, получить клетки/сок, экспорт, тесты |
| `ui.py` | Большинство интерфейсных панелей и свойств |
| `formbeere.py` | Free-заглушка платной ягодной формы |
| `formbeere_ui.py` | Интерфейс, зависящий от расширения ягодной формы |
| `form.py` | Форма клубники, взаимодействие с группами GN, семянки/впадины, назначение управляющих параметров, отложенные обновления; отдельная настройка Kiwi-сосудов |
| `formen.py` | Параметрические функции формы для разных плодов, прямые/обратные преобразования координат |
| `ananas.py` | Особые геометрические функции ананаса |
| `anlegen.py` | Подгонка внешней кожи и деталей по семенам, контакт/сопоставление |
| `vorschau.py` | Быстрые модификаторы семян, волосков, углублений, листьев |
| `farbe.py` | Окраска и переназначение материалов |
| `fast.py` | Быстрый режим, состояние, представления, буферы и подготовка к сложным операциям |
| `schnitt.py` | Переключение `PLATZ`, `FAST`, `GENAU` |
| `schnitte.py` | Режущие плоскости и укусы, Boolean/SDF, построение пустот, классификация свежих поверхностей |
| `biss.py` | Инструменты и UI для укусов |
| `biss_form.py` | Контуры/объём формы укуса |
| `durchdringung.py` | Проверка пересечений, изменение режима при взаимодействии резака с плодом |
| `leitbuendel.py` | **Специальный генератор сосудов клубники**: пучки, концы у семянок, 256³ атлас, полость и мостики |
| `hoehlung.py` | Дополнительные свойства/настройка внутренних стенок и полости |
| `zellen.py` | Восстановление/модификация GN-клеток на срезе и их рельефа |
| `saft.py` | Геометрия и материалы сока/капель на свежем срезе |
| `nachbau.py` | Восстановление частей сохранённых нодовых графов из JSON |
| `reissbrett.py` | Согласование/перенастройка материалов, цветов и групп сока/мякоти |
| `karten.py` | UI карточек и полей параметров |
| `aufloesung.py` | Переключение разрешений сетки и качества |
| `auswahl.py` | Список выбранных плодов и переключение активной части |
| `automatik.py` | Автоматическая смена режимов и реакции на интерактивные действия |
| `jobs.py` | Очередь работ, bake, проверка текущих операций, переключение состояний |
| `spawn.py` | Состояние исходных и созданных плодов, дубликаты, разделение, карты параметров |
| `teile.py` | Деление плодов на отдельные части и операции над ними |
| `teile_ui.py` | Параметры и панель частей плода |
| `gliederung.py` | Структура сгруппированных частей плода, их идентификаторы и внутренние имена |
| `gruppieren.py` | Сравнение и перенос подграфов между редакторами, группировка |
| `kontakt.py` | Объекты соприкосновения, поддержка семян/кожи |
| `knoten_zeigen.py` | Навигация к релевантным нодам из интерфейса |
| `ordnen.py` | Раскладка и оформление графов Geometry Nodes/Shader Nodes |
| `ordnen_texte.py` | Подписи и группировки графов |
| `licht.py` | Подключение студийного освещения |
| `studio.py` | Камера, осветительные установки, пресеты |
| `studio_ui.py` | Интерфейс студии и камеры |
| `physik.py` | Базовые физические операции с плодом/частями |
| `reihe.py` | Организация UI параметров, последовательности и управления |
| `umriss.py` | Отображение контура/резака во viewport |

**Файлы данных:** `daten/kiwi.blend` — рабочая Kiwi-сцена и 22 группы; `daten/zellen_saft.json` — сохранённые **части** клубничных GN/Shader групп (не целый платный проект); `daten/icons/` — иконки интерфейса.

Для вызовов/номерных строк каждой функции можно использовать машинный `inventory.json`, сохранённый отдельно в приватной папке исследования (не в публичной ветке, поскольку аудит внутренних имён не требует публикации полной реконструкции графов).
