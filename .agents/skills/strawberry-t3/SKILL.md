Read repository AGENTS.md and docs/t3-workflow.md. Read config/t3-agent-roles.json for exact role models and options. These project mappings replace upstream pstack Cursor Task/model slugs. Keep upstream skills unchanged.

Use the installed pstack feature playbook as method: trace, name the geometry parameter data, delegate bounded implementation, independently verify, review and deliver. Read relevant installed leaf skills rather than importing every skill. Do not call unavailable Cursor cloud agents, Bugbot, deslop or control-ui. Here, T3 delegation and Flue are the actual surfaces.

Recover queue with bd prime, bd ready --json and bd list --status in_progress --json from this checkout. Claim before implementation, link dependent tasks and record output paths, actual checks and unresolved findings. Beads owns working tasks; GitHub Issues own milestone acceptance; Git owns code and reports. Do not mirror every task as an Issue. Completion of technical work does not close visual acceptance.

Parent is manager and the only writer to live Blender. Implementation and reviewer get source/build paths, current owner directives and an acceptance brief, not the whole conversation. New review uses a fresh delegate. Use a T3-managed worktree when available for the actual repository; if the current T3 project is a parent scratch directory with a nested repository, use shared isolation with explicit disjoint file ownership and serialize review. Never construct child worktrees in shell.

Use config model provider/model/options literally through delegate_task. If unavailable, report and request selection; do not substitute. Manager settings describe this chat, not permission to change its model. No observer/heartbeat or parallel worker pool is enabled. No automatic merge, deploy, or third-party messages.

For visual work preserve prior milestones. Headless Blender builds into a new build version; validate reopened .blend, inspect a real preview, then parent preserves current GUI scene and opens the new version. Source provenance and measured versus artist parameters must remain explicit. Record limitations; owner assesses the look.
