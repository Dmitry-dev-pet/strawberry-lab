# Ботанические атласы, книги и первичная анатомия плодов

**Дата сверки:** 20 ноября 2026. **Назначение:** проверяемая библиография для универсального Fruit Engine, прежде чем создавать общие Geometry Nodes. Эта страница фиксирует *что действительно прочитано*, а не предполагает доступ к полному тексту каждой упомянутой книги.

## Правила источников

1. **Морфологические атласы и монографии** определяют происхождение органа, слои и топологию (чему соответствует структура). **Срезы, микро/гистологические исследования** определяют тип клеток, сосудов и количественные характеристики. **Фото/видео Frucht** оценивают только визуальное качество рендера.
2. У каждого измерения нужны таксон, сорт/генотип, стадия зрелости, конкретный образец, единицы, диапазон, метод и номер рисунка/таблицы. Переносить данные *F. vesca* на *F. × ananassa* или *A. deliciosa* на *A. chinensis* автоматически запрещено.
3. Статус доступа: **FULL** = доступна и исследована соответствующая часть текста/иллюстрации; **EXCERPT** = прочитан доступный отрывок; **ABSTRACT** = только реферат/описание; **BIBLIOGRAPHIC** = установлены выходные данные, полнота содержания неизвестна.
4. Не перепечатывать целиком закрытые иллюстрации/книги, не публиковать чужие необработанные микрофотографии в GitHub; ссылки, фигуры, краткое самостоятельно сформулированное описание и собственные графики допустимы. Видеореференсы Frucht хранятся отдельно на доступном владельцу Google Drive.

## Два обязательных ограничения

1. **Клубника — сборный ложный плод из цветоложа и семянок; киви — настоящая ягода из многоплодолистикового пестика.** Их нельзя получить из одного и того же `pulp+seed` меша простой сменой числа семян. Общими являются алгоритмы тканевых полей и сосудистых графов, а **спецификации происхождения органов и связей различаются**.
2. **Ни одно число в наших M1a–M1d (539 семянок, толщины сосудов, размер 0.115 Blender units для Voronoi) не становится измеренным фактом** от наличия атласа. Каждому физиологическому параметру нужны соответствующий экземпляр, стадия и цитируемое измерение; до этого это `ARTIST` параметр.

## Дальнейшая работа

Прежде чем строить Geometry Nodes:
- Составить 2 независимо подтверждённых графа органных связей и зон тканей: `Fragaria × ananassa` и `Actinidia deliciosa`.
- Для каждого узла/ребра графа сохранить `source_id`, `locator`, `evidence_level` и `species`.
- Сверить размеры клеток только по таблицам микроскопии и только для соответствующих таксонов и стадий.
- Затем описать **общий интерфейс** модулей `OrganIdentity`, `TissueDomain`, `CellPopulation`, `VascularGraph`, `SeedSite`, `SurfaceAccessory`; разрез/рендер оставить отдельными технологическими операциями.
- Из всех ссылок на платные книги используем только корректные библиографические сведения, не предполагая ознакомление с закрытыми главами.
