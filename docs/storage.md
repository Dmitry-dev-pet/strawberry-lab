**ACL:** папка Google Drive пока закрыта. Публичность GitHub не делает Drive-файлы общедоступными. Человек без доступа сможет воспроизвести новый рендер из кода; для скачивания *точных* исходных эталонов `.blend`/GLB потребуется доступ к Drive. Не делать папку «доступна всем по ссылке» без отдельного решения владельца.

## Восстановление точной версии v0.1

1. Авторизуйтесь в Google Drive с доступом к папке и скачайте девять файлов `v0.1-baseline` без переименования в одну директорию (или через подключённый Drive-коннектор ChatGPT).
2. Скачайте `assets/manifest-v0.1.json` и запустите **локально**, без авторизации в самом скрипте:

   ```bash
   python3 scripts/verify_assets.py assets/manifest-v0.1.json /path/to/downloaded/v0.1-baseline
   ```

3. Для просмотра/редактирования откройте `.blend` в Blender 5.2+; для GLB — используйте любой GLB-проверяющий просмотрщик. Для HTML Three.js нужен доступ к CDN.

Этот проверяющий скрипт **не содержит секретов, не скачивает файлы из Drive и не запускает бинарники**. Заголовки файлов проверяются лишь как первичный форматный smoke-test. Проверка происхождения `.blend` — это полное совпадение хеша и отдельный запуск Blender, а не одна сигнатура.

## Воспроизведение из общедоступного кода (без Drive)

Папка `src` позволяет снова построить исходные сцены и GLB (не гарантирует побайтное совпадение: файл Blender может включать метаданные/несохранённые настройки окружения). Открытые текстуры генерируются математически — без внешних фотографий:

```bash
python3 -m pip install -r requirements.txt
python3 src/make_tissue_textures.py
blender -b --python src/generate_strawberry.py -- --mode whole --preview --samples 24 --resolution 900
blender -b --python src/generate_strawberry.py -- --mode cut   --preview --samples 24 --resolution 900
```

В следующем эксперименте нужно сравнить **новые** результаты с исходным baseline по согласованным параметрам и рендерам, а не автоматически считать совпадение старых SHA-256 при каждом новом билде.

## Правила будущих версий

- Создавать папки `v0.2/`, `v0.3/` внутри Drive, не перезаписывать `v0.1-baseline/`.
- Новый манифест `assets/manifest-v0.N.json` публиковать в GitHub после **скачивания обратно и побайтной проверки** всех файлов.
- Код, тесты и настройки воспроизведения — GitHub; бинарники/рендеры — Drive.
- Каждый принятый эксперимент: metadata (Blender version, seed, samples, resolution, mesh count, duration), реальные whole/cut PNG, .blend, GLB и отчёт об отличиях от предыдущего baseline.
- В GitHub не коммитить учётные данные Google Drive, OAuth-токены, сырой журнал чужой приватной сессии или коммерческие материалы Frucht.
