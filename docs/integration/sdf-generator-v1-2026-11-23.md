## Реконструкция, тесты, ограничения
1. `PYTHONPATH=src python -m unittest strawberry_generator.test_recipe` — тест чистого recipe-контракта; зафиксировать фактический результат на этой ветке.
2. Требуются Blender 5.2+ и **приватные входные сцены** PR39 → PR40 с документированными SHA-256 (см. `src/strawberry_generator/README.md` и `src/strawberry_generator/sdf/README.md`). Один публичный GitHub checkout **не является автономной полной сборкой** и не содержит этих бинарников.
3. Генерация PR40-базиса → сборка native SDF → повторное открытие `.blend` без autoexec → `sdf/test_contract.py` и геометрические тесты `sdf/qa.py` в проверенном окружении Blender. Некоторые старые QA-пути указывают на соседний рабочий каталог; нужна отдельная нормализация, прежде чем объявлять portability PASS.
4. Запустить реальные сопоставимые Cycles whole, plane, bite, macro; визуальный A/B относительно приватного авторского видео. Контроль геометрии: два положения/поворота плоскости, сфера, отсутствие nonmanifold/нулевых полигонов, живой seed mask, сохранение реального rest-space и атласа.
5. После нового визуального A/B в отдельной маленькой ветке исследовать перенос core/halo и ослабления cell-outline из v20/v21 с сохранением единого FruitContext. Учитывать потерю pits при слишком грубом SDF.
6. Нужны независимые тесты, приватный editable `.blend`, оригинальные Cycles PNG, SHA-256 readback, измерение времени и памяти. Пока этой **новой end-to-end проверки интеграционной ветки нет**. Исторические PASS из PR42/46 не приписываются автоматически этому коммиту.
