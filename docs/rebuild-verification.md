# Clean rebuild of Strawberry Lab v0.1 — 20 ноября 2026

## Цель
Проверить, что опубликованный исходный генератор позволяет воспроизвести процедурные текстуры, GLB и редактируемые Blender-сцены без использования готовых файлов из Google Drive.

## Исходники и окружение
- Blender **5.2.4 LTS**, Linux x86-64, без GPU.
- `src/generate_strawberry.py`: точный Git blob SHA **9de5b9d88c32b318c5b13e6ea6f8aa94a563d5ea**. При подготовке локального теста убран только завершающий перевод строки, чтобы байты точно совпадали с содержимым GitHub.
- `src/make_tissue_textures.py`: Git blob SHA **eadca6730915bf732d63b6b13c09468d9198ee6b**, локальный код идентичен.
- Исходники скопированы в новую пустую директорию `strawberry-lab-clean-rebuild/`, не содержащую готовых моделей/текстур.

## Команды

```bash
python make_tissue_textures.py
blender -b --python generate_strawberry.py -- --mode whole --samples 1 --resolution 220
blender -b --python generate_strawberry.py -- --mode cut --samples 1 --resolution 220
```

Флаг `--preview` **не** указан, поэтому тест проверяет построение сцен и экспорт моделей, но не воспроизводит финальные рендеры.
