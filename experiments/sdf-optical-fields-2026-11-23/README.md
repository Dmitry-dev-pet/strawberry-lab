## Isolated A/B/C design
A = prior shadow-transparent scene (`361696819fd44733d560e3f59b101cd11f59862e7ebd7b7f83ce94fd07909963`). B and C are independent branches from A, not cumulative; both retain disabled shadow visibility on the juice object.

- B: only Principled Base Color of the existing juice material is newly linked. Read `sl_juice_clearance_mm`, a stored signed normal-direction gap between the tissue and optical surface; clamp to 0–0.20 mm, normalize to 0.10 mm, and raise each channel of the previous fixed tint to this exponent. Thin areas tend to white, a 0.10 mm gap gives the original tint, thicker gaps give stronger attenuation. Seven original shader nodes; no geometry or IOR/roughness/transmission change. This is an optical proxy, not a measured path length through a closed liquid volume or a physically verified absorption coefficient.
- C: only Principled Subsurface Scale of the existing cap material is newly linked. Read the existing `sdf_rest_position`, compute the radial distance from the fruit axis, use a smootherstep map over [0.12,0.75] model units from 0.006 to 0.020 model units (0.133–0.444 mm at the scene unit scale). The original scale was 0.012 model units; weight remains 0.08 and radius/color/roughness remain unchanged. Three original shader nodes; no new tissue or noise. These are scale settings, not a measured photon penetration distance.
