## Actual mechanism

`build_menisci.py` creates a separate, native live GN object. Blender ObjectInfo reads the **evaluated** same-cut body; material index 2 selects only exposed flesh, not skin. Named attribute `sdf_v20_halo` determines Poisson density on that actual cut surface. Fixed seed `19011`, minimum anchor distance 0.033 Blender units, density max 12 per BU². Each selected anchor instantiates a **closed 162-vertex/192-face low convex lens** oriented along the evaluated cut surface normal, with radius 0.31 mm, height 0.082 mm and submerged base 0.034 mm, uniformly random scale 0.78–1.38 (seed `8081`). Instances are **realized** as actual geometry, not shader dots. The lenses remain independent of the body mesh and physically overlap it; **there is no Boolean union, fluid dynamics, adhesion/contact-angle solver, or mass conservation**. Parameters are all `ARTIST`.

A: `sdf_meniscus_gain=0`, no lens geometry. B: same lens distribution with red weakly transmissive Principled material, found to produce dark spots. C: **exact same lens geometry**, with near-clear high-transmission waterlike material; this gave small glints but no recognizable juicy texture. The native property changes geometry live without executing scripts on file open. Source body, 264 seeds, native PR48 seed vertex guards, 150³ original atlas, 192³ v20 fields and previous materials are unmodified.

The 0.32 mm test was one five-pose run; the 0.20 mm test was split into four-pose plus single edge-bite runs after the original long session stalled. Thus **10 pose/resolution combinations × 3 variants passed**, with individual receipts in this archive. In each tested state:

- The evaluated original body coordinate SHA is identical for A/B/C, with **zero nonmanifold edges and positive signed volume**; original raw mesh/packed atlas SHA also identical.
- Every lens component is closed, with zero nonmanifold edges and positive aggregate signed volume. Each lens bottom center lies under the nearest body surface, and its top lies above, checked by signed normal-relative BVH closest-point probes for **every lens**.
- Whole mode has 0 lenses. At voxel 0.32: 29 straight-plane, 20 oblique, 10 ordinary bite, 26 open-side bite. At voxel 0.20: 25 straight-plane, 20 oblique, 13 ordinary bite, 22 open-side bite.
- `qa_live.py` separately verifies live 1→0→1 produces the exact original lens geometry, a rotated plane changes it, and a moved sphere changes it — with Blender scripts disabled.

This establishes **intersection/contact of a sparse set of independent lens solids in the tested states**. It does **not** prove topological fusion to tissue, contact everywhere along each footprint, or operation under arbitrary cutter shapes.
