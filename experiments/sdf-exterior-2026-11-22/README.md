# Strawberry Lab — SDF exterior + rest-space vessels (research proof, 22 Nov 2026)

**Status: ENGINEERING PASS / VISUAL FAIL (not accepted for main).**

A bounded independent Blender 5.2.2 experiment starting from our **sculpted exterior-v1**, not Frucht assets and not a copy of PR40's scene. It complements the earlier [seed101 SDF slice](../../src/strawberry_generator/sdf/README.md), which remains the more complete controls/LOD implementation.

## Reproduce

Requires Python/NumPy in Blender 5.2+, and the **unmodified local exterior** source from this repository:

```bash
B=/Applications/Blender.app/Contents/MacOS/Blender
$B -b --python src/build_strawberry_exterior.py -- --out build/exterior-v1 --no-render
$B -b --python experiments/sdf-exterior-2026-11-22/build.py
$B -b --python experiments/sdf-exterior-2026-11-22/tissue.py
$B -b --python experiments/sdf-exterior-2026-11-22/validate.py
$B -b build/sdf-vertical-slice/strawberry-sdf-vertical-slice-v3.blend --disable-autoexec --python experiments/sdf-exterior-2026-11-22/reopen.py
$B -b build/sdf-vertical-slice/strawberry-sdf-vertical-slice-v3.blend --python experiments/sdf-exterior-2026-11-22/render.py
```

The original `build/exterior-v1/strawberry-exterior.blend` is never overwritten. The prototype files and renders are kept under `build/sdf-vertical-slice/` (not committed to the repository). `STRAWBERRY_SDF_BASE` and `STRAWBERRY_SDF_OUT` can override the input/output paths for reproducible remote runs.

## Architecture actually exercised

- Original 157,250-vertex watertight exterior mesh with 264 separate achene meshes, physical pits and calyx.
- Editable native Geometry Nodes pipeline: `Mesh to SDF Grid → SDF Grid Boolean difference → Grid to Mesh` for the fruit; **same live cutter** drives signed-distance point-domain achene removal.
- Whole/plane/sphere selectable by frames **1/20/40** in one editable scene. Plane and sphere cutters remain movable. **This is a research layout**, not the existing PR40 `sdf_mode` interface.
- One packed, original-coordinate **128³ RGB atlas** for all cuts: handcrafted center pith, per-achene Bézier tube field and volume mottling. The same `fruit_rest` 3D attribute drives trilinear atlas lookup and cut-face Voronoi. Not 128³ measured strawberry cells, not 256³ Frucht code.
- Subtle cut-face GN displacement + shader bump. Whole fruit keeps the source's original shader/mesh.
- **Achene exclusion guard**: signed cutter distance of a seed center compared against 0.95 mm, greater than maximum original seed mesh radius 0.813 mm, so whole seeds touching the cutter are hidden instead of protruding into the cut.

Two real native Cycles 820×820 renders + plane macro rendered from the saved scene. **Visual acceptance FAIL**: vessel atlas renders as large white spots/short fibers, not anatomically credible continuous thin strands; cap lacks believable juicy cellular relief, material palette is too waxy. Original calyx is not cutter-controlled. No 0.20/0.32 voxel comparison was run for this experiment; its 0.27 mm voxel does not beat the earlier seed101 SDF branch's pit-depth measurements. No physically validated cell/vessel dimensions or wet-film measurements.

## Known engineering limitations

- The source calyx remains unchanged across cuts, and may overlap the removed body region.
- The 0.95 mm guard can create seed-free gaps near the cut rim; it is a conservative policy and not exact geometry clipping.
- The atlas uses artist-assigned branch paths and tissue colors, not specimen-specific histological measurements.
- The SDF resolution still rounds small pits and edges. No rigorous benchmark of SDF memory/performance versus the existing source, and no semantic export to GLB.
- Original coordinate positions are stored in GN before displacement; current shader atlas is packed inside the saved .blend. The external PNG is generated by the script.
- **Not ready to merge.** The next actionable task is cut lookdev against authorized frames from Frucht, with measured/verified geometry and explicit visual acceptance.

Original Frucht strawberry source was not used. The public author explanation and the independently inspected free Kiwi informed the overall strategy; no Frucht shader/nodes/meshes were copied. All parameters without primary data are ARTIST.
