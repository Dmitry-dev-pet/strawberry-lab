# Strawberry v20 — собственные ядро и ореол сосудистого поля

23 ноября 2026. Исследовательское продолжение [PR #46](https://github.com/Dmitry-dev-pet/strawberry-lab/pull/46).

**Результат:** отдельный широкий ореол действительно подавляет геометрический рельеф клеток вокруг того же узкого сосудистого поля. Это независимо проверено на вычисленной поверхности плоского среза и укуса. Во всех восьми проверенных состояниях основное тело осталось одной замкнутой компонентой и прошло строгие численные проверки. **Заметного общего улучшения фотореализма пока нет:** на общих планах A/B очень похожи, а цветное макро по-прежнему показывает сильную многоугольную сетку и размытые светлые пятна. На однотонном макро локальное сглаживание видно непосредственно.

Это `template-derived` исследовательская сцена, продолжающая собственные v12 → v18 → v19. Не новый генератор с нуля, не биологически измеренная ткань и не принятая в `main` продуктовая версия. Все новые размеры и коэффициенты — **ARTIST**.

## Что уточнено по исходному архиву

Повторно проверен предоставленный Free Kiwi 0.4.3 с SHA-256 `aaa218470ab068ed1cb806308d9a4da1d43fd5d9e3de30f6486ac7d204787877`. В нём действительно есть относящиеся к клубнике фрагменты Python-логики и сериализованные шаблоны клеток/сока, хотя коммерческой Strawberry-сцены нет. Прежняя формулировка про доступность «только Kiwi» была слишком узкой относительно содержимого исходников.

Узкое ядро, широкий ореол и радиальная координата относительно сосудистого кольца — разные данные. Уточнение к пользовательскому аудиту: G не только подавляет клетки, но и участвует в подъёме сосудистого рельефа вместе с R. Проверенная ветка шаблона смещает уже существующую поверхность среза; это иной механизм, чем сохранение объёмных трубок v19B. Подробные первичные опоры по файлам и строкам приведены в [уточнении аудита](reference-findings.md). Статическая трассировка этих фрагментов не доказывает полного поведения закрытой сцены.

В текущем опыте применён только общий инженерный принцип разделения полей. Исходники, ноды, материалы, меши и коэффициенты Frucht не переносились. Существующий собственный граф воспроизведён из наших 264 якорей и deterministic seed `19011`; его прежний raw R SHA воспроизведён точно.

## Чистое сравнение A/B

| Слой | A — core suppression | B — broad halo suppression |
| --- | --- | --- |
| Геометрия до рельефа | Один исходный native SDF difference → Grid to Mesh | То же самое |
| Узкое поле R | Собственный существующий граф | Побайтно то же поле |
| Подъём волокон | `0.18 × R × cap × rim`, мм | Тот же подъём |
| Поле, подавляющее клеточный рельеф | Узкое R | Более широкий H |
| Клеточная функция и её амплитуда | Унаследованные Voronoi/noise, strength=1 | Те же значения |
| Материал, pith, цвет, свет, камера | Исходные | Идентичны A |

Ширина Gaussian-ядер H увеличена в **1.8 раза** по σ относительно наших собственных путей. Используется `H = max(wider_graph, existing_R)`, поэтому ореол нигде не ниже R и при прежней монотонной функции подавления не может усиливать клеточную высоту. Коэффициент 1.8 выбран как ARTIST-параметр опыта, не взят из чужого пресета и не является морфометрией.

Для обоих вариантов сохранена прежняя clamped Smoothstep-функция: интенсивность `0.04…0.48` переводится в множитель клеточной высоты `1…0.12`. Следовательно, речь идёт о подавлении до 88%, а не полном занулении клеток. Общий сосудистый подъём добавляется **после** этого подавления и потому не меняется между A/B.

Первоначальный shader atlas не переименовывался и не переписывался:

| Источник | Каналы и назначение |
| --- | --- |
| Прежний material atlas | R — прежнее сосудистое поле; G — mottling; B — pith; A сохранён |
| Новый geometry atlas | R — копия существующего ядра для явного контракта; G — широкий ореол; B не используется; A=1 |

Ядро для фактического подъёма продолжает читаться исходным sampler из прежнего material atlas. Новый ореол читается собственной копией нашего trilinear sampler с отдельной интерполяцией Green. Оба используют один `fruit_rest` до смещения. Размер поля — **192³**, шаг XY ≈ 0.18848 мм, Z ≈ 0.26702 мм. Это объёмное поле, не отдельно нарисованная карта для каждого ножа.

Радиальная координата сосудистого кольца и отдельная геометрия сока в этот однофакторный опыт не добавлялись. Pith остаётся отдельной прежней маской. Диагностические кривые редактируемы, но изменение их точек не пересчитывает запечённый атлас автоматически; для нового поля нужно повторить сборку.

## Что изменено относительно v19 — отдельно от эффекта ореола

В обоих вариантах восстановлен прежний native SDF-путь. Дополнительное Volume Cube-пересэмплирование v18 и solid-tube union v19 отключены удалением 38 неиспользуемых узлов из каждой cut-группы. Связность не «доказывается» удалением островков после факта: новый рельеф смещает существующую непрерывную поверхность и не создаёт отдельные трубчатые объёмы.

Также в обоих вариантах добавлен общий небольшой подъём по R; его фактический максимум на проверенном плоском срезе ≈ 0.13577 мм. Поэтому сравнение старого v19 с новым v20 включает эти два общих изменения. **Только A против B внутри v20 изолирует ореол.** Исчезновение прежних красных шипов нельзя приписывать одному H.

Независимая проверка сохранённых файлов установила: все семь исходных material node signatures, исходный sampler и packed material atlas сохранены; в planar/bite группах A/B отличаются только Boolean `V20_USE_BROAD_HALO`. [Структурная проверка](evidence/independent_ast_review.json).

## Независимая проверка механизма на реальной геометрии

Валидатор временно обошёл последний Set Position в памяти, вычислил исходные позиции и нормали, затем восстановил связь без сохранения сцены. Они сравнивались с итоговыми вершинами, а не только с атрибутами, записанными сборщиком. Для каждой из двух поз совпали топология, базовые позиции/нормали, rest-координаты, R, H, ridge и cap/rim. Разность A→B объясняется именно изменением клеточной высоты.

| Измерение | Плоский срез | Укус |
| --- | ---: | ---: |
| Попарно сопоставлено вершин | 194 354 | 350 314 |
| Вершин со смещением > 10⁻⁶ мм | 52 141 | 43 427 |
| Максимальное реальное смещение A→B | 0.013784 мм | 0.013685 мм |
| Средняя абсолютная клеточная высота в области ореола, A → B | 0.009862 → 0.006019 мм | 0.010176 → 0.006220 мм |
| Вершин с увеличением абсолютной клеточной высоты в B | 0 | 0 |
| Максимальная ошибка `delta_position − normal × delta_cell` | 3.814×10⁻⁶ мм | 3.812×10⁻⁶ мм |

Область измерения определена заранее в отчёте: `halo > core + 0.05`, `cap_rim > 0.1`, `abs(cellA) > 10⁻⁶ мм`. В ней средняя абсолютная высота снижается примерно на **39%** в обеих позах. Допуск позиционной проверки — `10⁻⁵ мм`, учитывающий float32-запись координат. Это подтверждение механизма, **не процент улучшения реализма**. Полные [plane](evidence/v20-plane-causality.json) и [bite](evidence/v20-bite-causality.json) отчёты.

## Геометрическая QA

Сохранённые файлы открывались в свежих Blender 5.2.4-процессах с запрещённым autoexec. Строгий порог `1e-10 мм²` для **фактических треугольников**, а не исходных полигонов, не менялся.

| B: состояние | Вершины | Треугольники | Компоненты | Минимальная площадь, мм² |
| --- | ---: | ---: | ---: | ---: |
| Whole | 157 250 | 314 496 | 1 | 3.8718×10⁻⁵ |
| Plane | 194 354 | 388 704 | 1 | 2.4631×10⁻⁶ |
| Bite | 350 314 | 700 624 | 1 | 7.0729×10⁻⁷ |
| Plane moved | 154 762 | 309 520 | 1 | 5.6624×10⁻⁷ |
| Bite moved | 361 858 | 723 712 | 1 | 7.6125×10⁻⁸ |
| Plane rotated | 181 562 | 363 120 | 1 | 2.4631×10⁻⁶ |

Дополнительно прошли A plane и A bite: **8/8 проверенных состояний**. Везде ноль nonmanifold рёбер и вершин, ноль нарушений winding, положительный signed volume и конечные координаты. R/GBA исходного material atlas совпадают с закреплёнными SHA. [Сводка поз](evidence/pose_batch_summary.json).

Контроль старого дефекта показал, что в v19B plane было 51 251 внутренних треугольников с материалом кожи на расстоянии >0.5 мм от исходного hull. В v20B plane таких треугольников **0**; максимальное расстояние skin-треугольников — 0.07160 мм. Проверка использует центроиды и собственную исходную геометрию cut-body в согласованных координатах; это конечная диагностика этой позы, не универсальный классификатор материалов.

Seed guard проверил исходные и перемещённые plane/bite: **106 088 вычисленных вершин**, 0 внутри cutter по сохранённому nearest-normal критерию. Исходные seed meshes и `achene_center` совпали с v19A. Это не проверка пересечения всех треугольников и не доказательство прикрепления каждой семянки к мякоти. [Отчёт](evidence/v20b-seed-guard.json).

## Реальные рендеры и визуальный вывод

Получены **9 исходных Cycles PNG**: A/B plane, A/B bite, A/B цветной macro, A/B однотонный macro и B whole. Общие планы — 640×640, 24 samples; макро — 1024×1024, 32 samples и поле зрения 12 мм. CPU, seed `1729`, одинаковые камеры, свет, color management и denoising внутри каждой пары. Совпадение настроек проверено по журналам.

Сравнительные листы собраны из исходных PNG без изменения пикселей или размера изображений; добавлены только заголовки. На clay-макро материал заменён одинаковым нейтральным материалом без bump, coat и subsurface. Это отдельный диагностический вид, не улучшенная фотографическая версия.

**Наблюдение по изображениям:** на общих планах различие очень небольшое. На однотонном макро в B видны более широкие спокойные области вокруг тех же крупных форм; мелкая направленная рябь у A подходит ближе к их центрам. Цветной макро всё ещё определяется прежней многоугольной сеткой и светлыми пятнами. Мякоть не стала убедительно влажной тканью; наружная поверхность остаётся гладкой и восковой, а укус — довольно гладкой выемкой. [Независимая визуальная оценка](evidence/visual_review.md).

Значение H как отдельного геометрического сигнала подтверждено. Гипотеза, что одного его добавления достаточно для существенного приближения к визуальному результату автора, **не подтверждена этим опытом**. Свежего покадрового A/B с Frucht здесь не проводилось; приёмка владельцем не подменяется нашей оценкой.

Сборка двух сцен заняла 19.33 с. Отдельные 640px рендеры занимали около 11–22 с непосредственно Cycles; цветные макро — 123–133 с, clay — 28–31 с. Проверки иногда выполнялись параллельно, поэтому это наблюдённые времена данного запуска, не чистый сравнительный бенчмарк. Максимальный наблюдённый RSS среди рендеров ≈ 2.34 GiB; VRAM и интерактивная задержка ножа не измерялись.

## Воспроизведение

Нужен Blender **5.2.4 LTS**, build `cd5dc428cce1`, NumPy внутри Blender и собственный входной `strawberry-v19a-graph-only.blend` из приватного пакета:

`d89dd750f6f97bd7e85bce55eae0fb58af7d2a1dee9d07dc503932258a8b8110`.

В публичном репозитории `--v19-code` указывает на соседний каталог `v19-rooted-graph`. В полном приватном пакете необходимые собственные исходники лежат вместе в `source/`:

```bash
blender -b -t 4 --disable-autoexec --python-exit-code 1 \
  --python source/build_halo.py -- \
  --source input/strawberry-v19a-graph-only.blend \
  --v19-code source --out rebuilt

blender -b -t 2 --factory-startup --disable-autoexec --python-exit-code 1 \
  --python source/validate_saved_pose.py -- \
  --scene rebuilt/strawberry-v20b-halo-suppression.blend \
  --pose plane --output rebuilt/plane-qa.json

blender -b -t 4 --disable-autoexec --python-exit-code 1 \
  --python source/render_halo.py -- \
  --scene rebuilt/strawberry-v20b-halo-suppression.blend \
  --shot plane --out rebuilt/plane.png
```

Сборщик отказывается перезаписывать существующие выходные сцены. Инструкции независимой полевой проверки — [QA notes](QA.md). Кадры внутри сцен: **1 — whole, 20 — plane, 40 — bite**. Ножи остаются native Geometry Nodes-входами и обновляют геометрию без запуска Python после открытия.

Для всех девяти кадров в новом выходном каталоге можно вместо одиночного render запустить `python3 source/render_batch.py --blender /absolute/path/to/blender --out rebuilt`, затем `python3 source/make_comparison.py --out rebuilt`. Этот полный batch включает plane A/B, которые в записанном запуске были отдельно от остальных семи кадров.

SHA итоговых сцен:

- A: `a75e8cc7e21ff6fd83bcd26b85087cfafd83f534e10d40121021e2034806823f`.
- B: `35fd1d81c51aea1cc8f4cd71c39a2815da87a1137056d32c3f78d4ab1cf649e4`.
- Неизменённый packed material atlas: `02d8abd338b590451e0396a2e453e443aa60bfa1656f1f01ab2c1edaad238d65`.

## Оставшиеся ограничения

Не доказаны биологические размеры, отсутствие всех самопересечений и работа для любого положения ножа. Чашечка/плодоножка не получили новое отсечение. Отдельная геометрия сока, радиальная координата сосудистого кольца и переработка шейдерной сетки остаются самостоятельными задачами. Эти результаты следует сохранять как воспроизводимый визуальный эксперимент; численные PASS не являются основанием объявлять фотореализм или автоматически сливать исследовательский стек в `main`.
