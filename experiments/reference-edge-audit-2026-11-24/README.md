## 2. Direct behavioral checks in Blender

`probe_edge.py` is an independent harness that parses the pinned ZIP and executes selected **original** function definitions in memory on artificial small meshes with controlled scratch inputs. The private source stays in the ZIP; no node graph, preset values or result mesh exported. It also reopens the previously generated Kiwi snapshot, not a fresh complete original-add-on run. Source dispatch was evaluated under a minimal synthetic Strawberry name context, not by enabling a protected paid feature.

- The original `_rand_glatt` predicate returns true for `SCHNITTE • Entfernen` and false for `SCHNELL • Live Entfernen`. Registry inspection checks the presence of the optional clean-clip declaration, not the actual runtime behavior of the missing commercial model.
- Reopened original Kiwi Fast bite: skin modifier has 12 nodes (one SampleGrid, two DeleteGeometry, no SetPosition/MeshBoolean/GridToMesh). Flesh source has one GridToMesh, separate flesh cut modifier has one SDFGridBoolean, one SampleGrid and one GridToMesh. Actual graph evidence of split pipelines.
- Original `rand_knoten` on a synthetic 30-vertex/20-face strip with controlled inside-half-space field: after clipping, 20 vertices/12 faces. 5 surviving inside vertices projected to cutter, all 15 retained-side source vertices exactly preserved, no remaining negative-side vertex. This checks the snap operation in isolation, not SDF classification or curved cutter seam quality. First test failed from comparison of Python double .43 with Blender float32 coordinates; original source unchanged, test corrected to compare actual source mesh coordinates. Failure log retained.
- Original `naht_glaetten` on a synthetic **connected** 121-vertex/100-face two-material grid: 55 vertices moved, polygon indices unchanged, far vertices unchanged. On a synthetic **disconnected** 132-vertex/100-face grid with a gap between the parts: zero moved vertices, no new vertices/edges, polygon indices unchanged. This establishes the required common seam connectivity in the tested example; merely putting both meshes into Join Geometry does not make a shared seam. Not a measure of quality or physical gap closure in a fruit.
- Original flesh source and cut functions on an artificial sphere and plane box, using test-only dimensionless settings and **recession disabled** to compare stored pre-move distances: original hull 1490 vertices, remeshed reference 2936, cut tissue 1908. At all 1908 tissue vertices the stored `schnitt_rand_abstand` matches the actual remeshed reference triangle BVH to reported precision (max absolute error 0); difference versus original hull distances up to .009352 in scratch units. This confirms the source reference contract, not a biological dimension or accurate registration after recession. We did not test the cavity branch, exact paid body, or author-grade renders.

All four isolated geometry probes and dispatch/runtime checks completed. Exact receipts are in `results.json`. No new Strawberry render or fidelity claim.
