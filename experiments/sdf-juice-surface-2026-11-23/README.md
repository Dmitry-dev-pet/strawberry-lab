## Reference evidence and distinct hypothesis
Reopened owner-private `frucht-free-kiwi-0.4.3.zip`, SHA256 `aaa218470ab068ed1cb806308d9a4da1d43fd5d9e3de30f6486ac7d204787877`. `saft.py` reads original smooth position/normal, separates exposed cut geometry, and joins an extra geometry surface to the fruit. Static inspection of `daten/zellen_saft.json`, `saft` section, confirms three 3D smooth-nearest-centre Voronoi fields and a separate final Set Position, smooth shading and material. `reissbrett.py:saft_gruppe` additionally varies patterns radially and reduces wetness near the fruit axis. This is direct evidence about the accessible template, not an execution of the unavailable complete commercial scene. Unlike previous flat-film and scattered-lens negatives, this original experiment reconstructs an optical surface from our own stored smooth reference and normal and subtracts actual cell displacement to estimate where tissue protrudes.

## Native implementation
82 native Geometry Nodes; independent empty mesh object reads evaluated existing body. Three smoothly bounded fields in rest coordinates, warp, radial and skin-distance attenuation select connected cap patches. Liquid level measured from the smooth reference. Positive clearance above existing tissue or negative below it, not a uniformly displaced copy. Boundary vertices identified from vertex/face valence and tucked at least 0.018 mm below source tissue along the stored normal. Separate transmission material (IOR 1.333, roughness .13, full transmission), artist parameters. `juice_surface_gain` controls effect; whole, off, or disabled cell surface produce empty output. Body, seeds, cutters and upstream materials untouched. Open optical interfaces, not closed volumes, incompressible-fluid simulation, a measured juice quantity, or physical-contact validation. Boundary test is at mesh vertices along reference normals, not an exhaustive surface intersection proof. The initial 68-node control exposed 218 positive-clearance boundary points on plane; rejected and corrected (log preserved). No fresh 0.20mm or arbitrary-pose QA.
